# Dashboard de ventas

Dashboard web conectado a Google Sheets para monitorear cantidades vendidas de pulseras/brazaletes e items.

## Publicación en GitHub Pages

1. Crear un repositorio público en GitHub.
2. Subir `index.html` a la rama principal.
3. En GitHub, ir a `Settings > Pages`.
4. En `Build and deployment`, elegir:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Guardar.

GitHub entregará una URL pública para abrir el dashboard desde cualquier PC, celular o tablet.
